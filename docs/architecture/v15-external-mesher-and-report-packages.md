# v15 external mesher and deterministic report packages
The production CAD/tetrahedralization boundary is now executable as a file-exchange contract rather than a placeholder. `ExternalMesherArtifactProtocol` serializes healed CAD topology and meshing parameters to a versioned neutral JSON request. `ExternalProcessTetraMesherAdapter` owns process invocation, timeout/cancellation, stdout/stderr capture, artifact hashing and returned-mesh validation. `ImpactLab.MeshAdapter.Sample` is deliberately not a production mesher; it is a tiny executable contract fixture that converts a four-vertex neutral CAD request into one tetrahedron so the process boundary can be exercised after extraction.
Engineering reports now have deterministic package semantics. Markdown, HTML, CSV and canonical JSON are rendered from `EngineeringReportDocument`, hashed, and recorded in a versioned `manifest.json`. The manifest is an integrity contract for golden fixtures and reproducible exports; it is not a digital signature. Golden package verification checks safe relative paths, byte counts and SHA-256 values.
v15 does not claim that an external CAD kernel or tetrahedralizer ships with ImpactLab. Production geometry fidelity, mesher quality and executable adapter compatibility remain repository/runtime gates.
